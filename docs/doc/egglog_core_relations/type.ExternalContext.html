pub type ExternalContext<'a> = Option<&'a (dyn Any + Send + Sync)>;
Expand description

A borrowed value an embedder can make visible to every ExecutionState created for one operation, for its ExternalFunctions to read back with ExecutionState::external_context.

It is borrowed for exactly the operation that supplied it, so an embedder cannot mutate the state it shared while that operation runs.
