Expand description

Read-side methods — name-indexed table lookup and iteration. Implemented for ReadState and FullState; not for PureState or WriteState (a Write context body must not depend on live DB state).

The single-entry methods (lookup, eclass_of, contains) return None if absent — never insert. The iteration / introspection methods (function_entries, constructor_enodes, constructor_enodes_for_eclass, eclass_enodes, table_size, tables, table_sizes) walk the current contents of the database, while constructor_schema / function_schema / table_subtype report how a table is declared rather than what it holds.

Detectable misuse (wrong table subtype, wrong arity) is reported as crate::ApiError via the method’s Result. Per-column sort matching is not checked at this layer.

fn lookup<K: IntoValues>( &self, name: &str, key: K, ) -> Result<Option<Value>, Error>

Look up a function’s output value at the given key. Returns Ok(None) if the row is absent. The returned Value is raw — extract a Rust type via Core::value_to_base for base sorts or Core::value_to_container for containers.

Only valid for function tables. Constructors error; use Read::eclass_of for those.

Source

fn eclass_of<K: IntoValues>( &self, name: &str, inputs: K, ) -> Result<Option<Value>, Error>

Look up a constructor’s eclass at the given inputs, without minting a fresh one on miss. Returns Ok(None) if absent.

Only valid for constructor tables. Functions error; use Read::lookup for those.

Source

fn contains<K: IntoValues>(&self, name: &str, key: K) -> Result<bool, Error>

True iff a row with the given key exists in the table. Works for any subtype — never mints.

fn constructor_schema(&self, name: &str) -> Result<&'db FuncType, Error>

A constructor’s declared signature: its input sorts and the sort of the eclass column. Pair with Read::tables to walk every table.

Only valid for constructor tables. Functions error; use Read::function_schema for those.

fn function_schema(&self, name: &str) -> Result<&'db FuncType, Error>

A function’s declared signature: its input sorts and its output sort.

Only valid for function tables. Constructors error; use Read::constructor_schema for those.

fn table_subtype(&self, name: &str) -> Option<FunctionSubtype>

Whether the named table is a constructor or a function, or None if no table with that name is registered. Unlike the two schema accessors, a mismatch is not an error, so this is the one to dispatch on when either subtype is acceptable.

fn is_table_hidden(&self, name: &str) -> Option<bool>

fn is_sort_unionable(&self, sort: &ArcSort) -> Option<bool>

Whether sort is a unionable eq-sort, i.e. the output sort of a table whose rows are e-nodes. relations desugar to constructors over a fresh non-unionable sort, so this separates e-node tables from fact tables; pair it with Read::constructor_schema and Read::table_subtype. Returns None when no TypeInfo is visible to this execution (the e-graph’s internal rebuild rules).

fn constructor_enodes( &self, name: &str, f: impl FnMut(Enode<'_>), ) -> Result<(), Error>

Call f on each Enode of a constructor / relation table. Errors with WrongSubtype if name is a function. To stop early, use Read::constructor_enodes_while.

fn constructor_enodes_while( &self, name: &str, f: impl FnMut(Enode<'_>) -> bool, ) -> Result<(), Error>

fn constructor_enodes_for_eclass( &self, name: &str, eclass: Value, f: impl FnMut(Enode<'_>), ) -> Result<(), Error>

Call f on the Enodes of the one table name whose eclass column holds exactly eclass. For every constructor at once, use Read::eclass_enodes.

Rows whose eclass has since been merged into another are matched under the id they store, not their canonical one. Errors with WrongSubtype if name is a function.

Source

fn eclass_enodes( &self, eclass: Value, f: impl FnMut(Enode<'_>), ) -> Result<(), Error>

Call f on every Enode of eclass, across every constructor. Enode::name says which one each row came from.

A Value does not say what sort it belongs to, so this probes each constructor whose output is an eq-sort. A caller that already knows the sort should narrow to those constructors itself and use Read::constructor_enodes_for_eclass, which is one probe rather than one per constructor.

fn function_entries( &self, name: &str, f: impl FnMut(FunctionEntry<'_>), ) -> Result<(), Error>

Call f on each FunctionEntry of a function table. Errors with WrongSubtype if name is a constructor. To stop early, use Read::function_entries_while.
